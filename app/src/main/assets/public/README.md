# TEDEAGA Mobile (PWA)

Versão móvel instalável que reutiliza as telas e os recursos locais do TEDEAGA.

## Abrir no celular

Publique o conteúdo completo desta pasta em um endereço HTTPS. Abra o endereço no navegador do celular e escolha **Adicionar à tela inicial** (iPhone/Safari) ou **Instalar app** (Android/Chrome). O app guarda seus dados no armazenamento local daquele navegador. A primeira abertura online permite carregar os arquivos e usar o modo offline depois.

## Recursos

Agenda, tarefas, planos, metas, finanças, rotinas, alarmes em primeiro plano, importação de arquivos compatíveis e backup/restauração manual.

A sincronização com Google Drive, IA do mascote e widgets flutuantes do Windows dependem dos serviços nativos da versão desktop. Os alarmes podem não tocar quando o navegador ou o sistema suspender o app; para avisos confiáveis em segundo plano será necessário um serviço de notificações push.

## Dados

Os dados da versão móvel são separados dos dados do Windows. Para transferir, gere um backup no desktop e restaure no celular. Guarde cópias dos backups fora do dispositivo.
